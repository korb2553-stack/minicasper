# minicasper MUSIC

Discord Music Bot written in Python.

## Features

- Slash commands
- YouTube search and supported audio links
- Music queue
- Pause / Resume / Skip
- Volume control
- Loop
- Multi-server basic support

## Commands

/play
/pause
/resume
/skip
/queue
/volume
/loop
/stop
/leave
/help

## Environment Variables

DISCORD_BOT_TOKEN
OWNER_ID

## Requirements

Python 3.10+
FFmpeg
Discord Voice UDP support

## Hosting

Bot-Hosting.net

Startup file: main.py
